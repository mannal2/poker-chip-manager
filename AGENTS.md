# Repository instructions

- 코드 구조와 모듈 경계는 [ARCHITECTURE.md](ARCHITECTURE.md)를 먼저 확인한다.

- After completing each distinct task, run the relevant verification and commit that task's changes before starting the next task. This applies to all future work in this repository.
- Keep unrelated user changes out of task commits. Report failed or unavailable verification honestly.
- Commit locally; pushing, opening a PR, merging, and deploying require a separate user request.
