# 2026-10-21 중앙 팟·고정 보드·칩 이동

기존 codex/board-single-undo-main (348383a)에서 계속. 사용자 승인 내용:
1. 무르기 → 취소, 중앙 팟을 보드 위로, 5장 자리 고정(3번째 카드가 중앙).
2. 승자 선택 취소는 베팅 첫 버튼과 같은 좌표/크기, WIN은 우측3칸.
3. 저장 성공한 납부/반환/지급에만 360ms 칩 이동, 공동 수령 동시. 다음 핸드 블라인드는 생략.
4. 실패·초안·복원 재생 없음, 재시도 성공 1회. 취소/화면 이탈/회전 시 정리, 동작 줄이기 존중. 입력 차단 없음.

작업1: 레이아웃/문구 → verify: 보드 기존 좌표 고정, 팟 위치, 정산 버튼 동일 위치, 2~10인/작은/가로 겹침 없음.
작업2: 칩 이동 → verify: 실제 게임 엔진 금액으로 납부/반환/공동·사이드팟 지급, 저장 지연/실패/재시도와 복원/취소.
작업3: 회귀/독립 리뷰/production preview → verify: 단위/타입/린트/브라우저/PWA.
각 작업별 검증 후 로컬 커밋. 원격 변경 제외.
