# 화면 프로토타입 04

`index.html`을 브라우저로 열면 실행된다. 설치·서버·네트워크 요청 없이 동작한다. 실제 앱 소스나 게임 엔진으로 사용하지 않는 화면 검토 자료다.

## 확인할 내용

- 2·6·9인 원형/타원형 배치와 현재 차례 카드 강조
- 긴 이름·큰 잔액 표시
- 준비 화면에서 좌석을350ms 이상 누르고 이동하면 주변 좌석이 예상 순서로 이동하고, 놓으면 그 위치로 삽입
- 추가 금액·칩 버튼·올인 입력과 미리보기
- 카드 공개 시작 이후 취소 차단 안내
- 테이블 카드에서 다수 승자 선택, WIN으로 지급 후 다음 핸드 D·SB·BB 이동·블라인드 납부·첫 차례 표시

상단 시안 설정은 접을 수 있다. 인원·화면 변경 시 예시가 초기화된다. 베팅은 예시 잔액·팟에 반영한 뒤 쇼다운 화면으로 건너뛴다. 전체 행동 순서·미콜 반환·사이드 팟·탈락 후 데드 버튼 규칙은 구현하지 않았다. 따라서 실제 홀덤 계산용으로 사용할 수 없다. WIN 이후 표시는 탈락 없는 정상 사례 중심의 체험이며 온라인·저장·PWA도 없다. 브라우저를 닫으면 수정한 내용은 사라진다.

## 검증

2026-10-17 Chromium의320×568·360×640·390×844·430×932에서 각각2·6·9인 베팅 화면의 카드 겹침·가로 및 세로 넘침0건을 확인했다(시안 설정 접힘·키보드 닫힘). 카드 다중 승자 선택, WIN 후 칩 총량9,000 유지·팟15·다음 핸드 D/SB/BB/첫 차례, 드래그 중 주변 카드 이동과 놓은 뒤 순서를 확인했다. iPhone/Android 실기기·Safari·가상 키보드 상태는 미검증이다.

스타일·배치는 아직 제품 확정 사항이 아니다. React 구성·드래그 라이브러리 등 실제 기술 선택을 이 HTML로 확정하지 않는다.


## 시안 03 변경·검증

- 테이블 높이는 너비/1.12로 고정한다. 화면·A/B/C 전환과 무관하게 같은 크기와 위치를 유지한다. 하단 조작 영역도228px로 고정하며 남는 화면 높이를 테이블에 배분하지 않는다.
- 카드는 이름 아래 왼쪽 베팅액·오른쪽 남은 칩을 숫자로만 표시한다. 접근성 이름에는 숫자의 의미를 제공한다. 큰 숫자는 생략하지 않고 칸 너비에 맞춰 글자를 줄인다.
- A 금액 중심 / B 빠른 행동 / C 좌우 분리를 베팅 화면에서 바로 전환한다. 아직 최종안을 선택하지 않았다.
- 베팅 취소와 입력 초기화 C를 구분한다. 콜 금액·체크를 표시하고, 입력 후 예시 다음 차례로 이동해 취소를 체험할 수 있다. ‘공개 단계 →’는 시나리오 이동용이며 실제 라운드 완료 판정이 아니다. 폴드는 배치 검토용 안내 버튼이다.
- 공개 화면의 ‘카드 공개’ 한 번으로 공개 잠금과 정산 화면 진입을 처리한다.
- Chromium에서320/360/390/430px ×2/6/9명 ×4단계 ×3시안, 총144조합의 테이블 좌표·크기 고정, 카드 겹침0, 가로 넘침0, 하단 조작 영역 넘침0을 확인했다. 세 시안의 콜·취소·입력·공개·WIN과 큰 금액 표시도 확인했다.
- 이전 시안의 ‘320×568에서 세로 넘침 없음’은 이번 시안에 적용하지 않는다. 고정 테이블과 조작 영역으로 높이가 약612px(너비320)~710px(너비430) 필요하다. 짧은 화면에서는 스크롤을 허용하며 화면별로 테이블을 늘리거나 축소하지 않는다. 실기기·키보드 검증은 아직 없다.


## 시안 04 변경·검증 — 2026-10-18

두 줄 조작으로 확정하여 A/B/C 선택기를 제거했다. 메뉴 안에 기록·다음 핸드 블라인드 예약·중단과 시안용 라운드/공개 화면 이동을 제공한다. 실제 권한 인증은 없는 단일 기기 시안이다. 원형 칩 색은 시안 선택이며 보편적인 금액별 색상 규격을 의미하지 않는다.

핸드 누적액(contributions)과 스트리트 납부액(bets)을 분리했다. 카드 좌하단은 누적액+입력값, 우하단은 확정 잔액이다. C·BET·올인·취소·라운드 전환·새 핸드·예약 블라인드 적용을 체험할 수 있다. 사이드 팟·전체 베팅 규칙·폴드 처리는 여전히 제품 구현 전이며 실제 게임 계산용으로 사용하지 않는다.

Chromium에서20→70→80, C→20, BET 추가 차감, 취소 복원, 플랍 전환 후 누적20 유지·스트리트0, 새 핸드 예약 블라인드10/20 납부를 확인했다. 320/360/390/430px ×2/6/9명 ×4단계의48개 배치에서 테이블 좌표 고정·카드 겹침0·가로 넘침0을 확인했다. 실기기·키보드 상태는 미검증이다.
