# 화면 문구 정리 계획

작성일: 2026-11-08
상태: 초안. 사용자와 문구를 확정한 뒤 구현한다.

## 원칙 (사용자 결정 2026-11-08)

1. **말투는 합니다체**로 통일한다. 해요체("~할 수 있어요")는 쓰지 않는다.
2. **사람을 부르는 말은 "플레이어"**로 통일한다. "참가자"는 화면 문구에서 쓰지 않는다.
3. 문장 끝에는 마침표를 붙인다. 버튼 이름, 제목, 배지처럼 문장이 아닌 것은 예외다.
4. "해주세요"는 "해 주세요"로 띄어 쓴다.
5. 개발 용어(세션, 스트림, 요청, 명령, 조작권, 저장소 연결 등)는 화면에 보이지 않게 한다.
6. 포커 용어(폴드, 체크, 콜, 레이즈, 올인, 팟, 블라인드, 쇼다운)는 그대로 둔다.
7. 로컬 저장소 내부 오류(restore.ts 등)는 화면에 한 줄로만 보여 주고, 자세한 원인은 "오류 정보"에만 남긴다.

범위는 `frontend/src`의 화면 문구다. 서버 `ApiError.java`의 메시지는 화면에 쓰이지 않으므로 이번 범위에서 제외한다. 코드 주석과 테스트 이름은 바꾸지 않는다.

## 영향과 검증

- **e2e·단위 테스트**: 문구로 버튼과 안내를 찾는 테스트가 많다. 문구마다 옛 문구로 `frontend/e2e`, `frontend/tests`를 검색해 함께 고친다. 특히 `확인`/`닫기`/`취소`처럼 겹치는 이름이 새로 생기지 않는지 확인한다.

- **검증**: `npm run typecheck`, `npm run lint`, `npx vitest run`, 로컬·온라인 e2e 전체.
