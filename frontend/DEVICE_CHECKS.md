# 실기기 검증 현황

2026-10-18 기준. 현재 작업 환경에서 연결된 iPhone/Android 하드웨어를 사용할 수 없어 **실기기 항목은 미검증**입니다. 데스크톱 Playwright WebKit은 실제 iPhone Safari 검증을 대신하지 않습니다. 자동화의 정확한 결과는 IMPLEMENTATION_PROGRESS.md를 참조하세요.

## 자동화 환경

- Windows, Node 24.18.0, npm 11.16.0, Playwright 1.64.1.
- 번들 Chromium 156.0.8078.4 / WebKit 27.2.
- 320×568 및 360/390/430px, 2~9명, 최대 금액·10자 이름, 준비/베팅/정산의 레이아웃 검사.
- 승인 HTML과 동일 브라우저·동일 데이터의 이미지 비교. 시안 전용 상단 설정줄은 제품에서 제외.

## 기기별 확인 목록

로컬 앱을 신뢰할 수 있는 HTTPS 또는 기기 자체 localhost로 제공해야 서비스 워커가 동작합니다. LAN의 일반 HTTP 주소만으로 PWA 설치·오프라인 검증을 완료했다고 기록하지 않습니다. 실제 공개 배포는 별도 범위입니다.

- [ ] Safari/Chrome 일반 창에서 첫 준비·이름 한글 조합·숫자 키보드·길게 누르기와 스크롤·영역 밖/pointercancel 확인.
- [ ] 2/6/9명과 10자 이름/큰 금액에서 카드·역할·숫자·버튼 잘림 없음. 세로/가로 회전·safe area·작은 화면 세로 스크롤 확인.
- [ ] 자동 스트리트 → 전환 취소 잠금 → 동률/사이드팟 정산 → 다음 핸드 → 최종 우승.
- [ ] 취소, 마지막 폴드 확인 취소, 블라인드 예약 표시·다음 핸드 적용, HAND 기록 복원.
- [ ] 탭 2개 또는 설치 앱/탭 사이 명시적 인수와 이전 화면 차단.
- [ ] 오프라인 준비 완료 후 비행기 모드에서 새로고침·앱 재실행·앱 홈→단일 기기 모드·한 핸드 완료.
- [ ] 홈 화면 설치·아이콘·독립 창 실행. 홈 화면 앱과 일반 탭의 저장소 공유 여부 실제 확인.
- [ ] 잠금/백그라운드/강제 앱 종료 후 장부·공개 잠금 복원, 입력 초안 폐기.
- [ ] 업데이트 대기 중 게임 유지, 앱 홈에서 저장 완료 후 수동 적용, 전체 창 종료 후 복원.

## 검증 한계

저장 용량 실패는 실제 IndexedDB API 경계에서 QuotaExceededError를 주입해 검증합니다. 물리 저장 장치 고장이나 OS 강제 종료의 영구 보존을 보장하지 않습니다. schemaVersion1을 유지하며 구형 공개 중간 상태는 RESUME_FLOW로 원자적으로 정규화합니다. 실제 다음 DB 스키마 업그레이드 시 blocked 대기·변환·실기기 회귀를 다시 검사해야 합니다.

- [ ] 이름줄 직접 편집 Enter/바깥 탭/Esc/IME, 편집 중 시작 안내, 이름 입력과 D/드래그 구분, 지연 없는 D 반영.
- [ ] 앱 홈에서 저장 진행 게임 업데이트 후 복원. 조작권 상실 창에서도 홈/업데이트 이동.
